
1. Install "vsce" package from AUR.

2. Run "vsce package" in this dir.

3. Errors about missing commands may occur, e.g. "yarn" might be needed for the build.

4. The *.vsix file will be added in this dir upon success.

5. Build artifacts, e.g. under node_modules/ and out/, are not needed after .vsix is built.

6. In vscode find "Install from VSIX" command.
